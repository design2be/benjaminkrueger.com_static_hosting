Step 1: Join the Apple Developer Program

  • Go to developer.apple.com/programs.
  • Sign in with your Apple ID.
  • Enroll as an individual or organization.
  • Pay the yearly Apple Developer Program fee.

Step 2: Open the iOS project in Xcode

  • Open your Flutter project on a Mac.
  • Open ios/Runner.xcworkspace in Xcode.
  • Select the Runner project.
  • Select the Runner target.

Step 3: Configure signing

  • Open the Signing & Capabilities tab.
  • Select your Apple Developer Team.
  • Set a unique Bundle Identifier, for example com.company.appname.
  • Enable Automatically manage signing.

Step 4: Create the app in App Store Connect

  • Go to appstoreconnect.apple.com.
  • Open My Apps.
  • Click +, then New App.
  • Choose iOS, enter the app name, select the Bundle ID, add a SKU, and click Create.

Step 5: Fill in the App Store page

  • Add app description, keywords, category, support URL, and marketing URL if needed.
  • Upload iPhone and iPad screenshots.
  • Complete pricing and availability.
  • Complete age rating and app privacy questions.

Step 6: Set the Flutter version

  • Open pubspec.yaml.
  • Set the version, for example version: 1.0.0+1.
  • Increase the number after + for every new upload.

Step 7: Build the release IPA

  • Run flutter clean.
  • Run flutter pub get.
  • Run flutter test.
  • Run flutter build ipa --release.

Step 8: Upload the build with Transporter

  • Install Transporter from the Mac App Store.
  • Open Transporter and sign in with your App Store Connect account.
  • Find the generated IPA at build/ios/ipa/.
  • Drag the .ipa file into Transporter.
  • Click Deliver and wait for the upload to finish.

Step 9: Submit for App Review

  • Open the app version in App Store Connect.
  • Select the uploaded build.
  • Add review notes and demo login credentials if needed.
  • Click Submit for Review.
  • After approval, release manually or automatically.
